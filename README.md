# OS-02-UNIX-Commands-Shell-Programming

## Experiment 2: Illustrate UNIX Commands and Shell Programming

### Aim

To study and execute UNIX commands and implement basic shell programs.

### UNIX Commands

The following UNIX/Linux commands are demonstrated:

- date
- who
- whoami
- hostname
- pwd
- uname
- ls
- lscpu
- df
- cat

### Shell Programs

The following shell programs are implemented:

1. Greatest Among Three Numbers
2. Factorial of a Number
3. Sum of Odd Numbers up to N
4. Generation of Fibonacci Numbers
5. Arithmetic Calculator
6. Largest Digit of a Number
7. Palindrome Checking
8. Reverse of a Number
